# Help-X Mobile App

React Native app for drivers, riders, emergency contacts, and responders.

## Folder Purpose

- `src/features/countdown` - 30-second cancel countdown and emergency confirmation screens.
- `src/features/location` - GPS permission, background location, and trip tracking.
- `src/features/incidents` - Incident history, current incident status, and cancellation flow.
- `src/services` - REST API, socket, push notification, and device APIs.
- `src/navigation` - Stack/tab navigation.
- `src/store` - Global mobile state.

## Main Responsibilities

- Receive suspected accident alerts.
- Let user cancel false positives within 30 seconds.
- Share live GPS location during emergencies.
- Manage emergency contacts and profile data.
