# Help-X Web Dashboard

React + Tailwind dashboard for emergency monitoring teams.

## Folder Purpose

- `src/components` - Reusable UI and layout components.
- `src/features` - Business modules such as incidents, maps, auth, and notifications.
- `src/services` - API clients, socket clients, and integration wrappers.
- `src/store` - Global app state.
- `src/routes` - Route configuration.
- `src/hooks` - Shared React hooks.
- `src/styles` - Tailwind and global styles.

## Main Responsibilities

- Live incident dashboard.
- Map-based GPS tracking.
- Manual escalation and status updates.
- Police/hospital notification visibility.
- Admin management for users, devices, and responders.
