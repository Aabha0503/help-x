# Help-X Firmware

Firmware projects for ESP32 and Arduino-based accident detection hardware.

## Responsibilities

- Read accelerometer, gyroscope, vibration, speed, emergency button, GPS, and battery values.
- Run basic threshold checks on-device.
- Send telemetry and accident candidates using GSM/GPRS, Wi-Fi, HTTP, or MQTT.
- Receive configuration updates such as thresholds and reporting intervals.
