# ESP32 Help-X Firmware

## Folder Purpose

- `src` - Main firmware source files.
- `include` - Header files for sensors, GPS, GSM, and communication modules.
- `lib` - Local firmware libraries.
- `test` - PlatformIO firmware tests.

## Suggested Hardware

- ESP32 development board.
- MPU6050 or MPU9250 accelerometer/gyroscope.
- SW-420 vibration sensor or impact sensor.
- NEO-6M GPS module.
- SIM800L/SIM7600 GSM module.
- Emergency cancel button.
